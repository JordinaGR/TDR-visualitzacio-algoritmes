# Visualitzador d'Algoritmes d'Ordenació

Aplicació en Python dissenyada per visualitzar en temps real el funcionament de diferents algoritmes d'ordenació. Inclou una interfície gràfica, integració amb base de dades i lectura/escriptura de fitxers CSV.

> **Context:** Projecte desenvolupat el 2020 i presentat en el marc del Treball de Recerca (TDR) de Batxillerat.

1. Implementació d'alguns algoritmes d'ordenació
2. Interfície gràfica amb la llibreria **tkinter**
3. Emmagatzematge i gestió de dades amb **MySQL**
4. Lectura i escriptura d'un fitxer **.csv**
